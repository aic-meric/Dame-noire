# Dame noire

Prototype jouable dans le navigateur.

## Lancer localement
Ouvrir `index.html` dans un navigateur moderne.

## Mettre en ligne avec GitHub Pages
1. Crée un dépôt GitHub, par exemple `dame-noire`.
2. Ajoute `index.html` et `README.md`.
3. Dans **Settings → Pages**, choisis le déploiement depuis la branche principale et le dossier `/root`.
4. GitHub Pages publiera le jeu.

## Règles de cette version
5 joueurs, 78 cartes, 15 cartes chacun + 3 au chien, échanges droite/gauche selon la parité, fourniture obligatoire, atout obligatoire si la couleur est impossible, Excuse toujours jouable et ne remportant pas le pli, comptage des atouts par leur numéro, Dame de pique à 50, 281 selon les règles du projet, fin à 1000 points.

## Prototype
Les quatre adversaires sont actuellement des IA simples. L'étape suivante peut ajouter les niveaux de joueur, une IA dédiée au 0, une IA dédiée au 281, et une IA défensive contre les 281.
